# VLSI Lab

This repository contains my VLSI laboratory experiments, simulations, reports, and supporting files at VLSI Lab, Madan Mohan Malaviya University of Technology, Gorakhpur.

## Contents

The experiments cover CMOS digital circuit design and analysis using LTspice, including:

- CMOS inverter design and DC analysis.
- CMOS inverter voltage-transfer characteristic (VTC).
- Transient analysis of CMOS circuits.
- Power and delay analysis.
- CMOS NAND and NOR gate design.
- Transmission-gate implementation.
- CMOS stick diagrams and layout concepts.
- Design rule check (DRC) and layout-versus-schematic (LVS) concepts.
- Simple combinational circuit design and simulation.

## Tools Used

- WSL Ubuntu

## Experiment Format

Each experiment may contain:

- `report.md` — theory, procedure, observations, and result.
- `.asc` — LTspice schematic file.
- `.net` — generated or exported netlist, when required.
- `images/` — circuit diagrams, simulation plots, and screenshots.

## Objective

The objective of this repository is to document VLSI laboratory work in an organized and reproducible manner, including circuit design, simulation results, analysis, and technical observations.
